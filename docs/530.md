你是一名顶级科技商业路演PPT策划师、创业融资顾问、产品商业化专家和机器人/具身智能技术翻译者。请基于以下信息，为一个5分钟中文路演制作一份16:9 PPT。PPT要高度商业化、结构清晰、视觉现代，面向评委评分标准：商业潜力35分、技术实现30分、产品体验20分、“一人成军”15分。

## 一、项目基本定位

### 项目名

**Robot Task OS for Unitree**

### 副标题

**让宇树机器人从“演示设备”变成“可交付场景员工”的任务操作系统**

### 30秒核心定位

宇树已经把机器人身体做得轻、快、便宜、可二开；本项目补上真实落地最缺的一层：让机器人听懂现场任务、记住场景历史、调用企业工具、安全执行动作，并把每一步记录成可审计trace。

### 商业叙事

- 机器人硬件厂商卖“身体”；本项目卖“场景任务智能层”。
- 集成商卖项目；本项目卖可复用的任务编排、安全网关、记忆、工具连接器、审计平台和未来的工作流生态。
- Paid Pilot只是入口，真正的商业价值是把稳定场景工作流导出成可复用、可认证、可交易的Robot Workflow Package。

请不要只讲“Paid Pilot + SaaS”。要升级为“从垂直场景切入，再形成机器人工作流生态”。

### 商业化三段式

```text
阶段1：Paid Pilot
```

### 四类客户

| 客户 | 痛点 | 你卖什么 |
|---|---|---|
| 机器人OEM / 宇树生态 | 硬件强，但真实应用和生态需要补齐 | Task OS适配层、工作流生态、联合方案 |

| 第三方开发者 | 想参与机器人生态，但不想处理底层控制和安全复杂性 | Workflow SDK、Agent Registry、Marketplace |

- Connector Pack：工单、地图、知识库、IoT、数据库、摄像头等连接器。

## 六、必须解释清楚的“Robot Workflow Package”

请用一页或半页讲清楚：生态社区里交易的不是普通代码，而是：

> **Robot Workflow Package：可导出、可复用、可测试、可认证的机器人场景工作流包。**

它包含：

```text

```

一定要强调：

> **这是Certified Workflow Marketplace，不是随便上传代码的插件市场。因为机器人进入物理世界，必须有安全认证、仿真测试、权限控制和trace审计。**

## 七、技术创新必须这样讲

### 技术架构描述

请画成5-6层架构：

```text
用户语音 / 电话 / 远程主管
        ↓
Realtime Fast Brain：低延迟对话、打断、工具调用、现场决策
        ↓
Harness Task OS：任务编排、Agent角色、MCP工具、记忆读写、trace
        ↓
Slow Brain / Memory：Codex按需推理 + Phase1/2离线固化 + MEMORY.md
        ↓
Safety Gateway：11+1规则、FSM、Watchdog、E-stop、Vision Risk Gate
        ↓
Unitree Runtime：DDS / ComboController / RL Locomotion / Gesture / Motors
        ↓
RobotOps / Swarm：远程Bridge、Coordinator、Fleet Dashboard、共享记忆
```

### 技术创新表达

请使用这些表达：

1. **Realtime快脑**：低延迟语音、现场对话、打断和工具调用。
2. **Codex慢脑**：跨session记忆检索、复杂推理和离线总结。
3. **Harness任务编排**：把对话、工具、动作、记忆和trace接成闭环。
4. **安全动作网关**：慢脑只出建议，动作执行权回到快脑，所有运动工具必须经过安全网关。
5. **记忆飞轮**：每次任务产生的异常、确认、失败、工单和trace会沉淀为下一次任务的上下文。
6. **Workflow生态**：把稳定SOP打包成可复用、可认证、可交易的工作流资产。

### 不要这样说

不要说：

- “我首创快慢脑。”
- “我替代了宇树原来的视觉模型。”
- “我解决了机器人所有底层运动问题。”

要说：

- “快慢脑范式不是首创，我的贡献是把Realtime快脑、Codex慢脑、可grep记忆、安全网关和Unitree runtime组合成可运行、可审计、可复用的具身任务系统。”
- “我不替代底层控制，而是在宇树本体之上增加任务智能层。”
