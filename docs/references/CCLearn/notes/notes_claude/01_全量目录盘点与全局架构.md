### 6.2 核心数据流

```
用户输入
    ↓
[REPL.tsx] 捕获输入 → processUserInput()
    ↓
[query.ts] query() 异步生成器开始
    ↓
┌─ queryLoop() while(true) 循环 ─────────────────────────────────┐
│                                                                 │
│  1. 组装 systemPrompt (constants/prompts.ts)                    │
│  2. 注入 CLAUDE.md 记忆 (memdir/)                               │
│  3. normalizeMessagesForAPI() (utils/messages.ts)               │
│  4. 调用 Claude API (services/api/claude.ts)                    │
│     ├── 流式响应 StreamEvent                                     │
│     └── 解析 tool_use blocks                                    │
│  5. 工具执行 (services/tools/toolExecution.ts)                  │
│     ├── 权限检查 (hooks/useCanUseTool.tsx)                       │
│     ├── Hook 验证 (utils/hooks.ts)                               │
│     └── tool.execute()                                          │
│  6. 收集 tool_result → 追加到 messages                           │
│  7. 如果仍有 tool_use → continue (回到步骤 1)                    │
│  8. 如果到达 stop_reason → break                                 │
│                                                                 │
│  [检查点] auto compact? token 预算? stop hooks?                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
    ↓
[REPL.tsx] 渲染响应 → 持久化会话 → 等待下一轮输入
```

### 6.3 关键架构模式

#### 模式1：Feature Gates（特性门控）
```typescript
import { feature } from 'bun:bundle'
// 编译时死代码消除 — 外部构建不包含 Ant 内部功能
if (feature('BRIDGE_MODE')) { /* ... */ }
if (feature('KAIROS')) { /* ... */ }
```
**贯穿整个代码库**。用于区分 Anthropic 内部功能和外部发布版本。

#### 模式2：延迟动态导入
```typescript
// main.tsx / cli.tsx 大量使用
const { bridgeMain } = await import('../bridge/bridgeMain.js')
```
**目的**：最小化启动时模块加载。`--version` 快速路径零导入。

#### 模式3：buildTool() 工厂
```typescript
export const BashTool = buildTool({
  name: 'bash',
  schema: z.object({ command: z.string() }),
  execute: async (params, context) => { /* ... */ }
})
```
每个工具是独立目录，统一接口。

#### 模式4：AsyncGenerator 查询循环
```typescript
export async function* query(params): AsyncGenerator<StreamEvent | Message, Terminal> {
  // yield 每个中间事件 → 调用方（REPL/print）逐个消费并渲染
}
```
`query()` 是异步生成器，yield stream 事件和消息。REPL 和 print 模式分别消费。

#### 模式5：React + Ink 终端 UI
```
App (components/App.tsx)
  └── REPL (screens/REPL.tsx)
       ├── PromptInput (输入框)
       ├── Messages (消息列表)
       ├── StatusLine (状态栏)
       └── 各种 Dialog (权限、设置等)
```
完全使用 React 组件模型构建终端 UI，自定义 Ink 分支提供渲染。

#### 模式6：全局可变状态 (bootstrap/state.ts)
```typescript
// 1,758 行的单例状态
type State = {
  cwd: string
  totalCostUSD: number
  sessionId: SessionId
  modelUsage: { [model: string]: ModelUsage }
  // ... 50+ 字段
}
```
**注意**：代码注释写着 "DO NOT ADD MORE STATE HERE"。
