无交互 Headless 模式
Headless / Print Mode
cli/print.ts 5594 行
通过 -p flag 启动的非交互式执行模式。无 UI 渲染，直接将结果输出到 stdout。适用于 CI/CD、脚本集成和 SDK 调用场景。
  • runHeadless() 单次查询执行 · 无 REPL 循环
  • drain query generator 消费 AsyncGenerator 直到完成
  • 输出格式 / Output text · json · stream-json 三种格式
