流式工具执行器
StreamingToolExecutor · Pre-execution while streaming
services/tools/StreamingToolExecutor.ts
在模型流式输出 tool_use block 时，不等待完整响应，提前开始工具执行。 最大化并行度，减少端到端延迟。
  • addTool() 流式输出期间检测到 tool_use，立即投入执行
  • executeTool() 异步并行执行（Promise 不阻塞流）
  • getCompletedResults() 获取已完成的工具结果
  • getRemainingResults() 等待并获取剩余未完成结果
Model streaming → tool_use detected → addTool() → executeTool() async
↓ (streaming continues in parallel)
stream complete → getCompletedResults() + getRemainingResults() → merge

工具 Hook 系统
Tool Lifecycle Hooks
services/tools/toolHooks.ts
工具执行生命周期的扩展点系统。允许外部 hooks 在工具执行前后注入逻辑，实现监控、拦截、日志等功能。
  • runPreToolUseHooks() 工具执行前 hook 链
  • runPostToolUseHooks() 工具执行成功后 hook 链
  • runPostToolUseFailureHooks() 工具执行失败后 hook 链
