AgentTool 递归执行流程
从 tool_use 分派到嵌套 query 循环：agent 是如何调 agent 的
Step 01 · A
内置 agent 库
general-purpose、plan、explore、code-guide 等预置 agent 从源码目录直接读取
AgentTool/built-in/*.ts
Step 01 · B
自定义 agent
从项目目录下的 .claude/agents.json 读取用户或团队定义的专用 agent
loadAgentsDir.ts
Step 02
工具池过滤
按 ALL_AGENT_DISALLOWED_TOOLS 黑名单加 agent 自身配置裁出子 agent 可见的工具集
assembleToolPool · constants/tools.ts
Step 03
执行模式路由
在本地任务、远程任务与 git worktree fork 三种模式间挑一条，决定子 agent 跑在哪
LocalAgentTask · RemoteAgentTask · forkSubagent.ts
Step 04 · A
装配系统提示
getPrompt 拼装内置模板、agent 定义中的 systemPrompt 与当前环境详情
runAgent.ts · prompt.ts
Step 04 · B
创建 subagent 上下文
打包过滤后的工具集、独立 AbortController 与新 agentId，保证子 agent 状态隔离
ToolUseContext
Step 04 · C · Recursion
递归 query 循环
以 subagentParams 重新进入 query()，子 agent 可再次调用 AgentTool 形成多层嵌套
query(subagentParams)
Design Note
递归为何安全
每层独立的 agentId、AbortController 与工具池，让取消与权限决策天然按层隔离
runAgent.ts
Step 05 · A
收集输出消息
把嵌套循环产生的 assistant 消息汇总，打包成父循环能消费的 ToolResultBlockParam
AgentTool.execute()
Step 05 · B
后台摘要
若 agent 跑在后台，startAgentSummarization 异步压缩出结构化摘要供父 agent 引用
startAgentSummarization
Return
回到父 query 循环
返回值进入父循环的 tool_results 数组，父 agent 据此决定下一轮对话
ToolResultBlockParam

→
准备执行环境
→
递归执行 agent
→
返回父循环
