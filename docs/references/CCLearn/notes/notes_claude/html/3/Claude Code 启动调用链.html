Claude Code 启动调用链
从 cli.tsx 的动态导入到 query() 对话循环再到 bridge 远程出口的完整时序
Step 01
CLI 入口
进程启动点，解析命令行参数后动态导入主引导文件，延迟加载以提升冷启动速度
entrypoints/cli.tsx
Step 02
主引导装配
聚合所有启动步骤，决定走 REPL 还是 bridge 模式，是整条调用链的分叉点
main.tsx
Step 03
运行时初始化
读取用户设置、恢复会话上下文、准备工作目录，为后续装载提供干净环境
entrypoints/init.ts
Step 04
工具注册表
遍历 tools 目录聚合全部可执行工具，构建引擎后续分发需要的统一注册表
tools.ts · tools/*
Step 05
命令注册表
加载全部斜杠命令与插件命令，注入到 REPL 的命令路由供用户即时调用
commands.ts · commands/*
Step 06
分析与开关
初始化 GrowthBook 功能开关与埋点，控制灰度特性与运行时行为遥测
services/analytics/growthbook.ts
Step 07
REPL 启动
launchRepl 挂载 Ink App 组件并渲染 REPL 屏幕，等待用户输入触发一轮对话
replLauncher.tsx · screens/REPL.tsx
Step 08 · Core
query 对话循环
整个系统的心跳：协调消息归一化、提示装配、API 请求与工具调度的主循环
query.ts
Step 09
请求装配三件套
归一化历史消息、拼装系统提示、构造 Claude API 请求体，送给模型服务
messages.ts · prompts.ts · claude.ts
Step 10
工具编排
收到模型 tool_use 指令后，runTools 按顺序或并发调度工具调用，回传结果给循环
services/tools/toolOrchestration.ts
Step 11
单工具执行
查表定位具体工具，调用 tool.execute() 运行实现代码并收集输出或错误
toolExecution.ts · tools/*
Step 12
权限与钩子
执行前经 canUseTool 判断权限，再经 hooks 注入拦截逻辑，保证每次调用可控
useCanUseTool.tsx · hooks.ts
Aux A
自动压缩
当上下文逼近窗口上限时，autoCompact 把历史摘要化，让对话循环能持续推进
services/compact/
Aux B
附件与记忆
把 memdir 里的文件以附件形式挂到消息上，让模型能看到用户本地资料
attachments.ts · memdir/
Branch
Bridge 远程模式
main.tsx 的另一条分支，通过 sessionRunner 与 replBridge 把引擎暴露给远程会话
bridgeMain.ts · codeSessionApi.ts
