Layer 02 · 配置与依赖

query/config.tsquery/deps.ts
相位 2 · 每轮预处理
Layer 03 · 级别 1
ToolResult 预算裁剪
对超限的工具结果按 maxResultSizeChars 裁剪，持久化替换记录，与 microcompact 正交。
applyToolResultBudget
Layer 04 · 级别 2 & 3
snip + microcompact
轻量历史裁剪与微粒度压缩，删除冗余工具结果，tokensFreed 反向影响 autocompact 阈值。
snipCompactmicrocompact
Layer 05 · 级别 4
contextCollapse 折叠
读时投影把旧工具调用折叠为摘要，只修改发给 API 的视图，不污染 REPL 消息列表。
contextCollapse
Layer 06 · 级别 5
autocompact 全量压缩
接近上下文窗口时调用 Claude 生成摘要，yield postCompactMessages 并累积 taskBudget。
autoCompact.ts
相位 3 · 流式 API 核心
Layer 07 · 核心 · 模型调用
callModel 流式循环
向 Claude API 发起带工具和思维配置的流式请求，外层 while 支持 FallbackTriggered 后切模型重试。
deps.callModelFallbackTriggeredError
Layer 08 · 核心 · 事件分流
五重流式事件处理
模型 fallback、observable 回填、可恢复错误扣留、tool_use 收集、流式工具结果并行发射五条通路。
StreamingToolExecutortoolUseBlocks
相位 4 · 错误与恢复
Layer 09 · 恢复 A
413 prompt-too-long
先尝试 contextCollapse drain 消耗已暂存折叠，失败再走 reactiveCompact 全量响应式压缩。
reactiveCompact
Layer 10 · 恢复 B
max_output_tokens 恢复
先升级 OTK 从 8k 到 64k，失败后最多注入三次 resume 恢复消息，耗尽则浮出扣留错误。
maxOutputTokensOverride
Layer 11 · 错误与中断
tool_result 自愈
API 异常或用户中断时用 yieldMissingToolResultBlocks 补发错误 tool_result，防止下一轮 400。
yieldMissingToolResultBlocks
相位 5 · 后流程与循环
Layer 12 · 阶段 E
工具执行
流式路径取剩余结果，非流式走 runTools 串行编排，逐个 yield tool_result 给调用方。
runToolstoolOrchestration
Layer 13 · 阶段 D3
stopHooks 停止钩子
执行 stop/teammate hooks，preventContinuation 直接退出，blockingError 注入消息后继续循环。
query/stopHooks.ts
Layer 14 · 阶段 D4
tokenBudget 预算守卫
用量不足 90% 且未递减时注入 nudge 让模型继续，收益递减则停止并记录遥测事件。
query/tokenBudget.tscheckTokenBudget
Layer 15 · 阶段 H & I
附件注入与下一轮
合并 CLAUDE.md 变更、记忆与技能预取、排队命令，构建新 state 后 continue 回到循环顶部。
getAttachmentMessagesmaxTurns
