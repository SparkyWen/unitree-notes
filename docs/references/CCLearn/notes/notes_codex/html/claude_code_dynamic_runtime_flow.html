动态运行主流程
系统启动之后一次完整任务怎么跑完：从 argv fast-path 到 transcript 落盘
Step 01
用户启动 Claude Code / 输入任务
CLI 进程拉起，等待 argv 分流决定走哪条入口
Step 02
entrypoints/cli.tsx · fast-path 分流
argv fast-path 分流，简单命令直接处理，复杂路径懒加载 main.tsx
entrypoints/cli.tsx
Step 03
main.tsx · 初始化与模式路由
初始化主命令/模式，决定 interactive 或 headless，调 init.ts / setup.ts
main.tsx
Step 04
init.ts + setup.ts · 环境就绪
enableConfigs、safe env → full env、trust/onboarding/hooks、cwd/projectRoot/session、worktree/tmux/messaging/watchers/prefetch
init.ts · setup.ts
Step 05
构建运行时基础输入
settings 多源合并、config 读取、auth/provider 状态、命令池、工具池（含 MCP）、system/user context 生成
settings.ts · config.ts · auth.ts · commands.ts · tools.ts · context.ts
Step 06
进入 REPL / Headless 执行
交互模式挂载 REPL 屏幕，-p 模式直接 drain stream 到 stdout
Step 07 · Core
query.ts 主循环装配
准备 messages + system prompt + contexts + tools，执行上下文治理 snip / microcompact / autoCompact / collapse
query.ts
Step 08
services/api/claude.ts · 模型流式请求
构造 API params、注入 model/provider/auth/tool schemas/cache strategy、streaming 接收 assistant blocks
services/api/claude.ts
Step 09
assistant message / tool_use 到达
流式到达 assistant blocks，含文本与 tool_use 条目，流式执行器同步调度
Step 10
StreamingToolExecutor · 工具调度
runToolUse → toolExecution，pre/post hooks + permission + progress + tool_result
StreamingToolExecutor.ts · toolExecution.ts
Step 11
工具结果回灌
tool_result messages、file/plan/agent/deferred-tool/memory attachments、SessionMemory 相关记忆 prefetch
attachments.ts · SessionMemory/**
Step 12 · Core
query.ts 决策
还要继续吗？stopHooks / tokenBudget / continuation：需要则进入下一轮 queryLoop，结束则 transcript / config / memory / telemetry 落盘
Step 13
任务完成 / 等待下一次输入
本轮产物落盘，会话继续等待用户下一次输入或 headless 模式退出进程
Branch · 错误恢复
从 Step 08 分叉
withRetry 接住 prompt-too-long / media / max_tokens 错误，触发 fallback / retry / cooldown / compact retry
withRetry.ts · errors.ts
Branch · MCP 调用
从 Step 10 分叉
若调用的是 MCP 工具，走 mcp/client.ts 的 connect/call/retry/auth 与大输出持久化
services/mcp/client.ts
