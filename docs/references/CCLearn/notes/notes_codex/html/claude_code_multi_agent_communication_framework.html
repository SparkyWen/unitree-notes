Claude Code 多 Agent 通信框架
从 agent 调度入口到任务协作总线、消息通道与 swarm 执行后端的四相位全景
相位 01 · AGENT 调度入口
Layer 01 · 顶层调度
AgentTool 调度入口
leader agent 发起子 agent 行为的主实现,本身只做编排不做任务协作
AgentTool.tsxprompt.ts
Layer 02 · FORK 分支
forkSubagent 建立分支
fork 出新 agent 分支并建立新的 agent runtime 关系
forkSubagent.ts
Layer 03 · RUN 运行
runAgent 真正执行
连接 query runtime 与任务系统,驱动 agent 实际运转并回流输出
runAgent.ts
Layer 04 · RESUME 恢复
resumeAgent 断点续跑
恢复已有 agent,让多 agent 会话具备可继续性而非一次性
resumeAgent.ts
Layer 05 · 并发 SPAWN
spawnMultiAgent 共享编排
多 agent 并发 spawn 的共享编排层,工具链共用的底座
spawnMultiAgent.ts
Layer 06 · AGENT 来源
内建与外部双路加载
内建 agent 与用户目录 agent 可同时注入,能力边界可扩展
builtInAgents.tsloadAgentsDir.tsbuilt-in/*.ts
Layer 07 · 辅助与 UI
展示与颜色辅助层
agent 在界面上的视觉区分与通用工具辅助,保证多 agent 可读性
agentToolUtils.tsagentDisplay.tsagentColorManager.ts
相位 02 · TASK 协作总线 · 核心
Layer 08 · 协作核心
TaskCreate 总线入口
创建 task,是整个多 agent 协作总线的起点,也是协作的真正共享对象
TaskCreateTool.ts
Layer 09 · 状态查询
TaskGet 单点查询
读取单个 task 状态,leader 据此判断是否推进下一步
TaskGetTool.ts
Layer 10 · 全局视图
TaskList 协作面板
列出全部 task,让 leader 看到完整协作面板与多分支推进度
TaskListTool.ts
Layer 11 · 进度回报
TaskUpdate 回写通道
worker 回写状态与内容,是子 agent 汇报的主入口
TaskUpdateTool.ts
Layer 12 · 终止分支
TaskStop 中断控制
leader 终止某条协作分支,支持弃单和早停策略
TaskStopTool.ts
Layer 13 · 结果回流
TaskOutput 输出桥
显式把 task 结果回流到 runtime 与 UI,闭合协作链
TaskOutputTool.tsx
Layer 14 · 运行时绑定
Hooks 与分配消息
task 同时服务 runtime 与界面层,通过 hook 与分配消息双向联动
useTasksV2.tsuseTaskListWatcher.tsTaskAssignmentMessage.tsx

QueuedMessageContext.tsx

teammateMailbox.ts
