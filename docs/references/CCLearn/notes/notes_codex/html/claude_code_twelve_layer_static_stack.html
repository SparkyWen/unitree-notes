十二层静态架构
系统有哪些层、它们怎么叠在一起：文档第 3 节的完整分层视图
Layer 01
入口/启动/模式分流
fast path 分流、初始化 config/telemetry/trust/cwd/session、进入 interactive REPL 或 headless query
entrypoints/cli.tsx · main.tsx · init.ts · setup.ts · replLauncher.tsx
Layer 02
运行态状态/配置/设置/认证
global state、settings 多源合并、config 持久化、OAuth/API key/Bedrock/Vertex/Foundry 接入
bootstrap/state.ts · config.ts · settings.ts · auth.ts · api/client.ts
Layer 03
命令系统
slash commands、prompt commands、local / local-jsx 与插件命令的统一注册路径
commands.ts · commands/** · skills/** · plugins command path
Layer 04
工具系统
ToolDef 协议、权限/hook/exec、streaming executor、MCP tools 合并
tools.ts · Tool.ts · tools/** · services/tools/**
Layer 05
TUI/状态界面
Settings、dialogs、REPL、onboarding 等所有终端渲染与 state/app store 接入
components/** · state/** · screens/** · ink/**
Layer 06 · Core
Agent 主循环
组装 prompt/messages/tools/commands/context、调模型 streaming API、收 assistant/tool_use/tool_result、决定下一轮
query.ts · query/config.ts · query/deps.ts
Design Note
单一控制中枢
所有上下游都通过 Tool 抽象接入这一个循环，保证调度、权限与继续/停机决策的集中性
single hub
Layer 07
模型/API/重试
请求构造、stream parse、fallback 与 retry 策略，错误分类与日志
services/api/claude.ts · withRetry.ts · errors.ts · logging.ts
Layer 08
上下文治理
auto/reactive compact、history snip、continuation budget、停机钩子
compact/** · tokenBudget.ts · stopHooks.ts · microCompact.ts
Layer 09
记忆/附件/恢复
transcript/resume、memory prefetch、attachment injection
attachments.ts · sessionStorage.ts · SessionMemory/** · memdir/paths.ts
Layer 10
扩展平台
MCP servers/prompts/resources/skills、plugins、bundled/project/dynamic skills、workflows
services/mcp/** · plugins/** · skills/** · workflows/**
Layer 11
多 Agent/Task/Remote 协作
subagent/teammate/coordinator、background task、messaging、remote session、bridge/ssh/direct-connect/cowork
AgentTool/** · tasks/** · assistant/** · bridge/** · remote/** · server/**
Layer 12
基础设施与共用工具
path/fs/git/messages/token/schema/env 供所有上层复用
utils/** · constants/** · types/** · schemas/** · native-ts/**
